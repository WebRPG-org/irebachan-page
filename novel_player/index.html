    ノードグラフ

    操作方法

    • ジャンプ … タップ＝プレビューのみ（エディタのカーソルは動かない）／ダブルタップ＝移動して閉じる（閉じたあと設定どおりエディタも連動可）
    • if の枝 … 水色の箱をタップで @if へ（グラフは開いたまま）。枝は @endif で合流して続きへ。@goto / @end で終わる枝は箱から外へ出る
    • 表示 … ドラッグ＝パン、2本指ピンチ＝ズーム（PCはホイールも可）、「全体」でフィット
    • ＋ラベル … 脚本の末尾に追加
    • 改名・削除 … ボタンを押してからノードをタップ
    • 選択肢 … ラベルを1タップ → 文言と行き先を入力（新しい名前ならラベルも作成）。既存の選択肢は線タップでも編集（↑並べ替え・×削除）
    • 合流 … 合流先 → 枝を順にタップ（末尾を @goto 合流先 に）
    • ノードをドラッグ … 別ノードへ＝選択肢 / goto / call、空きへ＝新ラベルを作って分岐・goto・call
    • goto / call … 2タップ（出発→行き先）
    • end / return … 1タップ
    • 線 … タップで削除メニュー（すぐには消えない）。削除ツール中はタップで即削除。選択肢の線は編集ダイアログ（未接続はドラッグでもつなげる）

    灰線＝そのまま次へ続く　黄褐破線＝call
    ツールをやめる … 同じボタン／Esc　｜　戻す … ⚙内またはプレビューメニュー

    ヘルプ

    基本書式

    #キャラ名
セリフ内容（複数行可能）

    エディタに文字を打っているあいだ、# @ - => のボタンがエディタの下のほうに浮かびます。押すとカーソルの位置へ入ります。スマホではキーボードの上に出ます。

    変数（@set）

    変数に値を入れます。@if で使います。

    @set 好感度 = 0
@set 好感度 += 2
@set 鍵あり
@set !鍵あり
    • @set 名前 だけなら true、@set !名前 は false
    • = で代入、+= で足す、-= で引く。文字列は "太郎" のように引用符で囲む
    • プレビュー下の 変数 欄に今の値が出ます。タップで値を変更、↺ でリセット

    条件分岐（@if）

    変数の値によって、読む部分を分けます。

    @if 好感度 >= 3
仲良しのセリフ
@elseif 鍵あり
鍵を持っているときのセリフ
@else
それ以外のセリフ
@endif
ここはどの場合も読む
    • @if 条件 … 条件が当てはまるとき、次の @elseif / @else / @endif までを読む
    • @elseif 条件 … それより上の条件が当てはまらず、この条件が当てはまるときに読む。いくつでも書ける
    • @else … どの条件にも当てはまらないときに読む。書かなければ、当てはまらないときは何も読まない
    • @endif … @if の終わり。どの枝を読んだあとも、ここの次へ進む
    • 当てはまる条件が複数あっても、読むのは上から最初の1つだけ
    • 枝の中で @goto / @end すると、@endif には戻りません
    • 条件に使える記号: == != > < >= <=、かつ &&、または ||、否定 !
    • プレビューは変数の値を見て自動で枝に入ります。途中から再生して値が分からないときは、どの枝を読むかボタンで選びます

    選択肢

    - 選択肢テキスト => ジャンプ先ラベル

    選択肢の => ラベル はジャンプです。同じ選択肢に戻すときは枝の末尾で @goto 選択肢ラベル だけで足ります（@return は不要）。@return は、本文で @call したあと呼び出し元の続きへ戻るときだけ使います。

    ラベル定義

    @ラベル名

    ラベル行の左の三角を押すと、そのラベルの本文だけを折りたたみます。長押ししたまま上下に動かすと、そのラベルのまとまりを並べ替えられます。脚本の中身の記法は変わりません。

    ラベルへのジャンプ

    @goto ラベル名

    呼び出しと戻り

    @call ラベル名
@return

    シナリオ終了

    @end

    コメント

    // この行はプレビューに表示されず、エクスポート後もコメントとして残ります

    出力先への命令（そのまま出力）

    ![bg storage="room.jpg" time=500]
!show eileen happy

    行頭の ! を取った残りを、特殊形式出力にそのまま書き出します（改ページ記号や # は付かない）。プレビューでは無視されます。Ren'Py ではラベル内のインデントだけ付きます。

    表示ルール（作品ごと）

    ファイル内の @meta 〜 @endmeta にプレビュー用の表示ルールを書けます（位置は先頭固定ではありません）。

    @meta
preview.unit=block
preview.maxCharsPerLine=28
preview.maxLines=3
preview.overflow=wrap
@endmeta
    • preview.unit: block / line
    • preview.maxCharsPerLine: 1行あたり文字数
    • preview.maxLines: 表示行数
    • preview.overflow: wrap（折り返し）/ truncate（切り詰め）

    必要な行だけ書けば足ります。書かない項目は、文字数・行数は制限なし、あふれは折り返しです。シナリオメニュー内の 🧩 表示ルール からも編集でき、空欄・未設定にした項目は @meta から消えます。

    文字列置換（作品ごと）

    特殊形式出力・特殊テキストのコピー時だけ、出力テキスト中の文字列を置き換えられます。編集画面とプレビューは原文のままです。

    置換ルールも @meta ブロックに書きます。preview.* と同じブロック内で構いません。

    @meta
export.replace.旧名称=新名称
export.replace.【仮】=
@endmeta
    • 書式: export.replace.検索文字=置換後（1行1ルール）
    • 上から順に適用（先に書いたルールが先）
    • = の右を空にすると、その文字列を削除
    • @meta ブロック自体は脚本にも出力にも含まれません

    例: 執筆中の仮名称を出力時だけ本番名に差し替える、メモ用の 【仮】 を消す、など。

    特殊テキスト出力

    「特殊形式で出力」ボタンを使用すると、ゲームエンジン用の特殊記号付きテキストを出力できます：

    • 「。」の後に自動でクリック待ち記号を追加
    • テキストブロック内の行末に改行記号を追加
    • テキストブロックの最後に改ページ記号を追加
    • フォーマット変換のあとに、export.replace.* の置換を適用（上記「文字列置換」参照）
    • ティラノ / カスタム … 同じ変換（@if → [if exp]、@set → [eval] 等、@goto / @call / @return は設定のジャンプ・call・returnタグへ）。カスタムは他エンジン向けにタグ文字列を差し替えて使う想定
    • Ren'Py … if / $（@set）/ call / return 形式

    記号や形式は出力設定で変えられます。設定は作品ごとに @meta へ1行ずつ保存され（既定値と同じ項目は書かない）、手で書いても同じです。

    @meta
export.format=renpy
export.renpyStyle=name_quote_both
@endmeta
    • export.format: tyrano / renpy / custom、export.ext: 拡張子、export.unit: block / line
    • ティラノ: export.pageBreak export.lineBreak export.clickWait（true / false）export.clickWaitSymbol export.punctuation export.labelSymbol export.labelBelowTag export.jumpTag export.callTag export.returnTag export.choiceLine export.choiceEnd
    • Ren'Py: export.renpyStyle（name_quote / name_quote_both / quote_only）

    表示の切り替え

    画面上部右の □ を押すと、表示が次の順で切り替わります。

    分割（プレビュー＋エディタ）→ プレビュー全画面 → エディタ全画面 → 分割 …

    分割のときは、中央の区切り線をドラッグして幅を変えられます。

    作品・ファイル

    • 起動時は最後に開いていた作品を自動で開く（空ならサンプル）
    • 作品は画面上部で切り替え（ブラウザ内に自動保存）
    • 外に出すときは エクスポート（UTF-8。対応ブラウザでは保存先を選べる。選べない Android では共有シート）
    • 渡すときは コピー / 共有（コピー済みのうえ共有シートが開きます）
    • インポート／貼り付け … 新規作品 or 上書きを選択（貼り付けは HTTPS / localhost のみ）
    • 流れに整列 … @ラベル ブロックを goto / 選択肢 / call の流れどおりに並べ替え（要確認。元の並びは自動では戻せない。「戻す」で1手のみ）
    • 特殊形式で出力 … ティラノ / Ren'Py 等へ変換。作品ごとの文字列置換は @meta の export.replace.*（書式タブ「文字列置換」参照）

    進行

    プレビュー画面では、次のどれかで進められます。

    • ▶ 次へ / ◀ 戻る
    • メッセージ枠をタップ
    • → / ←（エディタに入力中でないとき）

    エディタのカーソル行から始める：画面上部の ▶（またはプレビュー操作メニュー内）、Ctrl+Enter（Mac は ⌘+Enter）

    プレビュー表示中の行をエディタで開く：画面上部の ✎（またはプレビュー操作メニュー内）、Ctrl+Shift+Enter（Mac は ⌘+Shift+Enter）。メッセージ枠タップで次へ進む操作は変わりません。

    ノードグラフ

    画面上部の ノードグラフ で分岐を俯瞰します。変更は脚本テキストへの反映です（正本はエディタの記法のまま）。

    • ジャンプ … タップ＝プレビューのみ／ダブルタップ＝移動してグラフを閉じる
    • if の枝 … 箱をタップで @if へ（グラフは開いたまま）。枝は @endif で合流
    • 表示 … パン・2本指ピンチでズーム・「全体」。ラベル名フィルタ
    • ＋ラベル … 脚本末尾に空ブロックを追加
    • 改名・削除 … ツールオン → ノード1タップ（削除は確認あり。参照も整理）
    • 選択肢 … ツールオン → ラベル1タップ → 文言と行き先を入力。行き先が新しい名前ならラベルを起点の直後に作成し、各枝の最後を「元の続き」などへ合流。選択肢があるラベルでは既存の選択肢を編集（↑並べ替え・×削除・行き先を空で未接続）
    • 合流 … ツールオン → 合流先をタップ → 枝を順にタップ（末尾の @goto / @end / @return を @goto 合流先 に置き換え）
    • ノードをドラッグ … 別のノードで離す＝選択肢 / goto / call を選択、何もない所で離す＝新ラベルを作って選択肢・goto・call
    • goto … 2タップ（末尾の @goto / @end / @return を置き換え）／call … 2タップ（@call 行を追加）
    • end / return … ラベル1タップ。ツールのやめ方は同じボタンをもう一度、または Esc
    • 線タップ … 削除メニューを表示（選んだときだけ @goto / @call / @end 等の行を削除）。削除ツールがオンのときはタップで即削除。選択肢の線は編集ダイアログを開く（未接続選択肢の線はドラッグでも接続）
    • 戻す … グラフまたはプレビューメニュー（ラベル欄）。Ctrl+Z も可（エディタの Undo とは別）

    灰点線は定義順の fallthrough、黄褐破線は @call。プレビューメニューの「ラベル」は一覧からのジャンプ向け、グラフはつながり編集向けです。

    プレビューメニュー（ラベル）

    • チップタップ … ジャンプ（メニューは開いたまま。任意で閉じる）
    • ＋ 追加 … 末尾に @ラベル
    • 改名 / 削除 … オンにしてからチップタップ
    • 戻す … グラフの「戻す」と同じ操作履歴

    Novel Draft

    ブラウザでシナリオを書きながらプレビューするエディタ。作品は端末内に保存、共有はテキスト想定。

    • 即時プレビュー（分割 / 全画面切替は右上 □）
    • 作品の自動保存・エクスポート / インポート・コピー / 共有、ティラノ / Ren'Py 向け出力
    • HTTPS 配信時は PWA（ホーム画面に追加・オフラインで UI 表示）
