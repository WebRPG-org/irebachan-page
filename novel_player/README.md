# Novel Draft

ブラウザでシナリオを編集しながらプレビューできるツールです。共有はテキストのやりとりで行うことを想定しています。

## できること

- **編集とプレビュー**（分割 / 右上□で全画面切替）。編集中は # @ - => がエディタの下のほうに浮かぶ。ラベル行の左の三角で本文だけ折りたたみ、長押しでそのまとまりを並べ替えられる
- **作品の自動保存**（このブラウザ内に複数保持、切り替え可能）
- **エクスポート / インポート**、**コピー / 共有**、**特殊形式出力**（ティラノ / Ren'Py）
- **PWA**（HTTPS 配信時にホーム画面へ追加・オフラインで UI を表示）

## 使い方のイメージ

1. シナリオメニューで作品を選ぶ（＋で新規、✎で名前変更）
2. プレビューしながら編集（内容は自動保存）
3. 外にファイルとして残すときだけ **エクスポート**
4. 別端末やバックアップ用に渡すときは **コピー / 共有** またはエクスポートした `.txt`
5. 外から取り込むときは **インポート** または **貼り付け**（新規作品 / 現在の作品に上書きを選択）

## 表示テーマ

- 各テーマは `themes/presets/{id}.css`（1ファイル1テーマ）
- `themes/presets.css` は `@import` の一覧だけ（新規はファイル追加 + import 1行）
- エディタは `{id}.css` を書き出し。`presets.css` へ丸ごとコピペしない

## ノードグラフ

画面上部の **ノードグラフ** で、ラベル間のつながりを俯瞰しながら脚本（`.txt` 記法）を直せます。変更はすべてテキスト正本への反映です。

### 表示・操作

| 操作            | 内容                                                           |
| --------------- | -------------------------------------------------------------- |
| 空白ドラッグ    | パン（移動）                                                   |
| ホイール / ＋－ | ズーム                                                         |
| **全体**        | 全体を画面に収める                                             |
| ノードタップ    | プレビュー・エディタをそのラベルへ移動（**グラフは閉じない**） |
| フィルタ        | ラベル名でノードを絞り込み                                     |
| **×** / **Esc** | グラフを閉じる                                                 |

- ノード下に本文プレビュー（約40字）
- **灰の点線** … 定義順で `@goto` なしのときの続き（fallthrough）
- **黄褐の破線** … `@call`
- 未接続の選択肢はスタブ（点線）で表示
- `@if` はラベルの下で枝分かれ（水色の箱＝条件と本文の先頭）→ `@endif` に合流 → その下が続き。`@goto` / `@end` で終わる枝は合流せず箱から外へ出る。`@else` が無いときは点線の「どれも偽」が `@endif` へ直行

### ツールバー（ラベル）

| ボタン       | 使い方                                                                          |
| ------------ | ------------------------------------------------------------------------------- |
| **＋ラベル** | 脚本**末尾**に空の `@ラベル` を追加                                             |
| **改名**     | オン → ノード1回タップ（参照の `@goto` / `@call` / 選択肢も更新）               |
| **削除**     | オン → ノード1回タップ（**確認あり**。ブロック削除＋他からの参照を外す）        |
| **戻す**     | 直前のグラフ／ラベル操作を1手戻す（プレビューメニューの「戻す」と同じスタック） |

グラフ表示中は **Ctrl+Z**（Mac は **⌘+Z**）でも戻せます。エディタの元に戻すとは別です。

### ツールバー（分岐）

| ボタン     | 使い方                                                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **選択肢** | オン → ラベルを1タップ → ダイアログで「文言 → 行き先」を複数行入力。行き先が新しい名前ならラベルを**起点の直後**に作成。選択肢があるラベルなら既存の選択肢を編集 |
| **合流**   | オン → まず**合流先**をタップ → 枝のラベルを順にタップ（各枝の末尾の `@goto` / `@end` / `@return` を `@goto 合流先` に置き換え） |

選択肢ダイアログの「新しく作る枝の最後」:

- **元の続きへ合流**（既定）… 起点にあった続き（`@goto X` / `@end` / 定義順の次ラベル）を各枝の末尾へ移す。起点は選択肢で終わる
- **「X」へ合流（既存の枝と同じ）** … 既存の選択肢の枝がすべて同じラベルへ `@goto` しているとき
- **何も書かない** / **指定ラベルへ合流** も選べます

既存の選択肢の編集: **選択肢の線（またはスタブ）をタップ**するか、選択肢ツールでそのラベルをタップすると、同じダイアログに既存の選択肢が読み込まれます。文言・行き先の変更、**↑** で並べ替え、**×** で削除、行の追加をまとめて反映します（行き先を空にすると未接続の選択肢）。

### ノードからドラッグ

ノードを押したままドラッグして離すと、離した場所に応じてメニューが出ます。

| 離した場所       | メニュー                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| 別のノード       | 選択肢でつなぐ… / goto / call                                                                  |
| 何もないところ   | 選択肢で分岐… / goto で新ラベルを挟む…（起点の続きは新ラベルへ） / call で新ラベルを呼ぶ…（末尾 `@return`） |

### ツールバー（接続）

| ボタン               | 使い方                                                                      |
| -------------------- | --------------------------------------------------------------------------- |
| **goto**             | 起点ラベル → 行き先ラベル（ブロック末尾の `@goto` / `@end` / `@return` を `@goto 行き先` に**置き換え**） |
| **call**             | 起点 → 行き先（`@call` 行を**都度1行追加**）                                |
| **end** / **return** | ラベル1つタップで `@end` / `@return` を追加                                 |

ツール選択のやめ方: **同じボタンをもう一度**、または **Esc**（何も押していないときが通常＝ノードタップで移動）。

**矢印・スタブをタップ** … 削除メニューが出て、選んだときだけその接続を脚本から削除（`@goto` / `@call` / `@end` 等の行）。**削除ツールがオンのときはタップで即削除**。選択肢の線は（削除ツール以外では）編集ダイアログが開きます。

**未接続の選択肢の線** … ドラッグして別ラベルへつなげる。

行き先のラベルがまだ無いときは、末尾に `@ラベル` スタブを自動追加します。

### プレビューメニューとの使い分け

|            | プレビューメニュー「ラベル」 | ノードグラフ              |
| ---------- | ---------------------------- | ------------------------- |
| 向くこと   | 名前で探して**ジャンプ**     | **構造**の確認・接続編集  |
| 追加       | ＋ 追加（末尾）              | ＋ラベル（末尾）          |
| 改名・削除 | トグルオン → チップタップ    | ツールオン → ノードタップ |
| 戻す       | あり（共有）                 | あり（共有）              |

メニューは開いたままジャンプし、必要なら自分で閉じる使い方で問題ありません。

## ノードグラフ（dagre）

縦方向レイアウト用に [dagre](https://github.com/dagrejs/dagre) を `js/lib/` に置きます（初回または clone 直後）:

```bash
cd novel_player
mkdir -p js/lib
curl -fsSL -o js/lib/graphlib.min.js "https://cdn.jsdelivr.net/npm/graphlib@2.1.8/dist/graphlib.min.js"
curl -fsSL -o js/lib/dagre.min.js "https://cdn.jsdelivr.net/npm/dagre@0.8.5/dist/dagre.min.js"
```

## PWA（ホーム画面に追加）

**HTTPS**（GitHub Pages など）で開いているときだけ有効です。`file://` 直開きでは登録されません。

- **Chrome / Edge（Android 含む）**: メニュー → 「アプリをインストール」／「ホーム画面に追加」
- **Safari（iOS）**: 共有 → 「ホーム画面に追加」

オフラインでも編集画面は開けます（作品データは IndexedDB に保存された分）。**オンライン時はサーバーから最新の HTML/JS を読みます**（古いキャッシュに張り付かない方針）。`SHELL_FILES` の構成を変えたときだけ `sw.js` の `CACHE_NAME` を上げてください。

アイコンを作り直す場合（要 Pillow）:

```bash
cd novel_player
python3 -c "from PIL import Image, ImageDraw, ImageFont; ..."
# または icons/icon.svg を差し替え
```

```
novel_player/
  index.html, styles.css, manifest.webmanifest, sw.js, pwa.js  … 入口・PWA
  editor/          … CodeMirror エディタ（build.mjs で bundle 生成）
  icons/           … PWA アイコン
  js/
    core/          … プレイヤー本体・メニュー初期化
    lib/           … 共通ユーティリティ（保存・クリップボード等）
    storage/       … 作品の IndexedDB 保存
    ui/            … パネル分割・レイアウト
    script/        … 記法パーサー・参照エラー
    export/        … ティラノ / カスタム（同一変換）/ Ren'Py 等への出力
  docs/            … 設計メモ
```

エディタのビルド: `npm run build:editor`（`editor/scenario_editor.mjs` → `scenario_editor.bundle.js`）

## 記法

- `#キャラ名` の次の行からがセリフ
- `@ラベル名` でラベル定義
- `- 選択肢 => ジャンプ先ラベル`（戻るなら枝の末尾で `@goto` 選択肢ラベル。`@return` は `@call` 用）
- `@goto ラベル名` でジャンプ
- `@call ラベル名` と `@return` で呼び出し・戻り
- `@set 好感度 = 3` / `@set 好感度 += 1` / `@set 鍵あり` / `@set !鍵あり` で変数に値を入れる。今の値はプレビュー下の「変数」欄に出る
- `@if 条件` … `@elseif 条件` / `@else` … `@endif` で条件分岐。最初に当てはまった枝だけ読み、`@endif` の次へ進む。プレビューは変数の値で自動判定（値が分からないときはボタンで選ぶ）
- 特殊出力では `@set` / `@if` をティラノ（`[eval]` / `[if exp]`）・Ren'Py（`$` / `if`）の書き方に変換
- `@end` でシナリオ終了
- `!` で始まる行は出力先向けの命令。プレビューでは無視し、特殊形式出力では `!` を取った残りをそのまま出力（例: `![bg storage=room.jpg]`。Ren'Py ではラベル内のインデントだけ付く）
- `@meta` … `@endmeta` に作品ごとの設定を1行ずつ書く。`preview.*`（表示ルール）、`export.replace.*`（出力時の文字列置換）、`export.*`（出力設定。`export.format=renpy` など。出力設定ダイアログで変えるとここに書かれる）
- 詳細はツール内の「ヘルプ」を参照してください。

## call / return の確認（3分）

1. **選択肢から枝** … 会話 → `@goto` で選択肢ラベルへ戻り、**選択肢が再表示**されれば OK
2. **本文 @call** … `@call` の直後に `@ラベル` が続いても、`@return` 後に **本編の続き**（別枝のラベルに吸われない）なら OK
3. 迷ったらブラウザコンソールで `novelPlayer.getPreviewDebugState()` … `callStack` が空なのに return した等を確認

ラベルチップでジャンプすると call スタックはリセットされます（意図どおり）。
